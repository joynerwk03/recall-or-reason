1

Neither model uses the confidence scale

Every multiple-choice answer carried a confidence from 0 to 100. Across all 160, not one fell below 80 — and each model used exactly four distinct values all day. A scale exercised only from 80 to 100 is not measuring confidence, it is decorating an answer.

2

Asked for a range instead, one model finds its footing

The same 50 numeric items, asking for an estimate and an 80% interval. devstral covers 72% — statistically indistinguishable from the 80% requested. The rescue is not free: lfm2 covers 32% and is overconfident in both formats.

3

Does the width mean anything?

Coverage says the intervals are the right size on average. This asks whether they are in the right places: a model with self-knowledge widens exactly where it is about to be wrong, putting its answers along the diagonal.

Move the question and see what moves with it

Eight variants, each shifting one thing — the year, the country, the population — to a value where the true answer genuinely differs, every answer traced to a primary source. An anchor echo is an answer landing closer to a figure the model was already holding than to the truth. devstral produced none. lfm2 produced five.

5

Four ways this instrument lied

Every result above survived a bug that had already produced a confident, plausible, wrong number. These are in the report because the fixes are the reusable part.

i

Non-determinism wearing the costume of determinism

The CLI path ran with no sampling options while the HTTP function directly beneath it set temperature: 0 and carried the comment "Deterministic, so a re-run of the same items is comparable." The CLI path is the one that runs on this machine. Three days of numbers were single draws from a stochastic decode.

The first fix was worse than the bug. Piping /set parameter temperature 0 ahead of the prompt looked like it worked — but ollama run with piped stdin treats all of stdin as the prompt, so that line was silently prepended to every question as text. Two later runs then differed on 35 of 50 items.

The tell was there and initially missed: the "pinned" answer (20) was not a value the unpinned run had ever produced (1, 2). Temperature 0 narrows a distribution; it does not move it somewhere new.
ii

A parser that manufactured accuracy

lfm2 writes ranges as LOW, ESTIMATE, HIGH. The parser assumed the prompted ESTIMATE, LOW, HIGH, so every ascending triple put the estimate outside its own interval — producing 11 of lfm2's 12 "incoherent" answers, which had been written up as a finding about the model.

Worse: on an item whose truth was 9, 9 / 90 / 100 was read as estimate 9 — scoring a perfect baseline off a misread, which then made a well-formed wrong answer look like catastrophic degradation.

Lenient parsing buys coverage and pays in ground truth. Any parse yielding a self-contradictory answer is a suspected misparse before it is a finding.
iii

A metric that inverted under a ceiling effect

The perturbation gap first reported lfm2 at −0.05 and printed "no meaningful degradation" — the opposite of the truth. A model already 96% wrong on an original has no room to get worse, so being wrong twice scored as robust. Restricting to pairs where the model got the original right moved it to +0.51.

This is why the headline above is anchor echo, not the gap: echo is defined on every item regardless of baseline accuracy.
iv

A correlation that reversed the model ranking

Width and error were both normalised by the true value. Two ratios sharing a denominator correlate even when independent — Pearson's spurious correlation of ratios, 1897. The distortion had no consistent sign: devstral 0.761 → 0.281, lfm2 0.312 → 0.501.

Reported that way, it would have swapped which model looked like it knew what it did not know.

What this does not establish

  • It rules out reciting a single headline figure. It does not rule out recall. These variants are verifiable precisely because one source publishes the whole series — which makes their answers well-published too. A model that had memorised the entire Gallup trend table would pass this test cleanly.
  • n = 8 perturbations, 50 intervals, 80 items, two models, one prompt version. p = 0.026 is one experiment, not a replication.
  • No scale ladder. The two models are the same size — 24.0B and 23.8B. Their on-disk footprints (15GB, 14GB) read like a big model and a small one and are not. Nothing here speaks to scale.
  • One ground-truth defect found, not yet repaired. The extreme-poverty item anchors 1990 at 36%, while the World Bank $3.00 (2021 PPP) series puts 1990 at 43.4% and 36.2% at 2000. Excluded from the variant work and flagged.
